The name of this project is H.I!🖐.

Of course, you can read it as a greeting.
It stands for Human Intelligence.

-- CONTEXT --
Why?

Information and media have always played a major role in shaping society.

We are living through quite peculiar times, when this influence is not only amplified but also chaotic and difficult to navigate.

This affects everyone, but especially younger generations, who may have had fewer opportunities to encounter different perspectives and develop a critical understanding of what they consume.

Not to mention that control over these channels is concentrated in the hands of a few (we'll set aside for now whether we should judge them).


-- MISSION --
What?

The main tools shaping this landscape are social media and AI.
There are also newspapers, TV, and so on, but we have little or no control over them.

Some might argue that social media and AI are also beyond our control.
But that's only true if we remain passive consumers.

The project aims exactly to change that.
Its purpose is to turn this situation around: to give more people the tools to move from being passive consumers to active participants, to use these tools rather than be used by them.


-- PROJECT --
How?

By building all the tools needed to achieve that goal.

We'll start with short, informative videos and messages.

The vision is broader and more ambitious.
It could include a web platform that deepens understanding and offers other ways to learn and stay up to date.
It could also bring the project into the physical world through in-person classes and meetups.

I could go on and on, but for now we'll focus on what we can do today, with the resources we have.
It's not much, but we have to start somewhere.
